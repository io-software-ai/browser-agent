# 商店資訊 — 繁體中文

## 名稱（上限 75）

Browser Agent

## 摘要（上限 132，純文字；同 manifest 的 description）

放進瀏覽器的 AI agent，直接操作你正在看的網站：讀頁面、點擊、填表，也能跨網站研究並附上來源。

## 完整說明

Browser Agent 把 AI agent 放進你的瀏覽器，直接操作你正在看的網站。用平常說話的方式交代——摘要這頁、把價格整理成表格、幫我填這張表、找到取消訂閱的設定——它會讀懂頁面、直接動手，每一步都顯示出來。一頁不夠時，它也會跨網站做研究，給你附來源的答案。

直接操作你正在看的頁面
它會讀取目前分頁、點擊、輸入（包含下拉選單）、捲動、在頁面之間移動。模型看到的是網頁真正的結構——頁面文字和編號過的按鈕、連結、欄位清單——不是看截圖猜位置。選一段文字就只問那段；PDF 也行。

附來源的研究
問頁面回答不了的問題，例如「2026 年 React 狀態管理該用哪個？」它會用你自己的瀏覽器在背景分頁搜尋、讀最相關的幾頁（包含你登入後才看得到的頁面），依你的問題濃縮每一頁的重點，再給你結論、比較表和推薦。回答裡的每個 [n] 都連回出處，回答下方會列出有引用到的來源。你目前的分頁完全不會被動到。

主控權在你手上
遇到看起來不可逆的動作（付款、下單、刪除、送出表單）前，擴充功能本身會停下來，要你按「允許」才繼續。agent 要讀它自己組出來的網址時也會先問；區域網路裡的頁面，除非網址是你自己打的，否則不讀。網頁沒辦法說服模型跳過這些確認。每一步都看得到，隨時可以停；每個任務最多 40 步。

免費開始，也可以用自己的金鑰
裝好就能用 Browser Agent Cloud，每月有免費點數，不用登入。每個任務依模型、思考深度和讀多少字扣幾點，送出前側邊欄會顯示預估。付費方案有更多點數。想用自己的供應商？改用自己的 API Key：Claude（Anthropic）、OpenAI、Google Gemini、OpenRouter，或任何 OpenAI 相容端點，包含你自己架的模型（Ollama、LM Studio、vLLM）。之後請求會從你的瀏覽器直接送到該供應商，不扣點數。

功能
• 頁面工具：讀取頁面、點擊、輸入（包含下拉選單）、捲動、開啟頁面
• 研究：在你瀏覽器的背景分頁搜尋與閱讀，每一頁依你的問題整理重點，來源有編號、[n] 引用可以點
• 選取文字：在頁面上選一段，只針對那段發問
• 附加檔案：把文字檔、程式碼或 PDF 拖進來、貼上或選取，跟訊息一起送出
• 專案：每個專案有自己的指示、檔案和記憶，也可以只開部分技能。專案裡的每個對話都會先讀它的指示，專案檔案則是 agent 需要時才打開
• GitHub 專案：把專案連結到 GitHub repo，用起來就像 Claude Code——agent 讀 repo 裡的檔案，並把你一個一個允許的改動 commit 進去。agent 會照 repo 的 CLAUDE.md 或 AGENTS.md 裡的慣例做事
• 讀 PDF，包含沒有文字層的掃描檔（以圖片送給 Claude，一定要你按允許才會送——見下方隱私）
• 12 個內建技能，打 / 挑選：/summarize、/translate、/extract、/compare、/explain、/thread、/reply、/fill-form、/review-pr、/checklist、/decide、/grill-me
• 用 Markdown 寫自己的技能，或從 GitHub、skills.sh、ClawHub 安裝（Agent Skills 標準：SKILL.md、技能資料夾、.zip）；裝來的技能會標成第三方、當成不可信內容處理，技能附帶的程式不會執行
• 選擇題卡片：需要你做決定時，用可點的選項問你
• 檔案下載：結果可以存成 CSV、Markdown、JSON 等純文字檔
• 記憶：說「記住……」，它會記得關於你的簡短事實；可以在設定裡查看、編輯或關閉
• 歷史：每個專案最近 30 則對話連同來源存在你的電腦上，可以打開接著聊，或匯出成 Markdown
• 首頁有依你目前頁面產生的建議
• 淺色與深色主題；介面有 15 種語言

隱私
你的對話、記憶、專案（包含它的檔案）、技能和設定只存在你的瀏覽器裡（chrome.storage.local）。Cloud 模式下，請求會經過我們的伺服器送到 AI 模型供應商；我們會保留用量紀錄（模型、token 數、點數）來計算點數，不會保留你的訊息、頁面內容或模型的回覆。用自己的金鑰時，請求直接送到你的供應商，完全不經過我們。連結 GitHub repo 時，擴充功能是從你的瀏覽器直接連到 GitHub，不經過我們的伺服器。研究用的是你自己的瀏覽器：搜尋就是從你的瀏覽器做 Google（或 Bing）搜尋，網頁會帶著你的登入狀態載入。付費方案透過 Paddle 購買，付款資料由 Paddle 處理。沒有廣告、沒有第三方分析。開始之前，擴充功能會先顯示一段簡短說明並請你同意。完整隱私權政策：https://github.com/io-software-ai/browser-agent/blob/main/store/privacy-policy.md

## 常見問題

**要付費嗎？**
不用。Browser Agent Cloud 每月有免費點數。每個任務（你送出一則訊息，到 agent 停下來為止）依模型、思考深度和每頁讀多少字扣固定的點數，送出前側邊欄會顯示預估。付費方案有更多點數。如果改用自己的 API Key，擴充功能免費，你付給模型供應商實際用量的費用；用本機模型則完全不用錢。

**會送出哪些資料？送給誰？**
你要它做事時，你的訊息和相關的頁面內容（或你選取的文字、你正在讀的 PDF）會送給 AI 模型：預設經過 Browser Agent Cloud 轉給模型供應商；用自己的金鑰時直接送到你的供應商。Browser Agent Cloud 只保留計算點數用的用量紀錄，不保留內容。研究時，搜尋是從你的瀏覽器送到 Google（或 Bing），讀的網頁會在背景分頁帶著你的 cookie 載入，就跟你自己打開一樣。在專案裡，每次請求會帶著專案的指示和記憶；你附加在訊息裡的檔案，以及 agent 打開的專案檔案，也會一起送出。專案連結了 GitHub repo 時，repo 的 CLAUDE.md、AGENTS.md、記憶檔和 agent 讀到的 repo 檔案也會一起送出；連到 GitHub 的連線本身不經過我們的伺服器。沒有文字層的掃描 PDF，只有在你按下確認卡片上的「允許」之後，才會以圖片送給 Claude。側邊欄停在新對話的首頁時，每次打開側邊欄、切換分頁或頁面載入完成，首頁建議都會把目前頁面的標題、網址與開頭約 800 字送給 AI 模型；Cloud 模式預設開啟，可以在設定裡關掉。

**它會自己買東西或刪東西嗎？**
不會不先問你。下面這些都要等你在側邊欄按「允許」，卡片會說明將發生什麼：看起來不可逆的點擊（付款、購買、刪除、送出、授權、發送、發布、分享等 15 種語言的字詞，比對按鈕的可見文字、無障礙標籤、title 與 value——可見文字跟標籤不一致時會提醒你）；表單裡或有密碼欄頁面上的純圖示按鈕；在表單外按 Enter 送出（聊天框、留言框）；有好幾個欄位或有密碼的表單；前往任務開始時的網站與你訊息提到的網站以外的頁面；讀取 agent 自己組出來的網址（牽涉網址的卡片會顯示網址與查詢字串，因為網址本身就能把資料帶出去；太長的會截短）；以及對話裡已經有網頁內容或檔案（網頁、PDF、專案檔案、連結的 repo 裡的檔案、附件）之後：前往 agent 自己組出來的網址（就算是任務開始時的網站或你提到的網站）、輸入不是你訊息裡的文字、寫入或刪除記憶、前往 GitHub 上能直接改 repo 的頁面（新增、編輯、刪除、上傳檔案的頁面，以及 github.dev，就算是讀過的頁面裡的連結）。每一次寫進連結的 GitHub repo，以及每一次在 repo 裡記住或忘記事情，也都要等你允許，不管對話裡有什麼。寫檔的卡片會顯示檔案和改動，並在 repo 不是私人的、或檔案在安裝或建置時會被執行時警告你。agent 不能寫給 AI agent 的指示檔（CLAUDE.md、AGENTS.md 這類）；點開頭的檔案與資料夾（.github/、.npmrc、.vscode/ 等等）也只能寫少數常見的，例如 .gitignore、.editorconfig。連結的 repo 裡的 CLAUDE.md、AGENTS.md 和記憶檔跟網頁內容一樣處理：agent 會照裡面的慣例做事，但它們不能代替你允許任何事，上面的規則從任務一開始就適用（任務開始時讀不到 repo 也一樣）。點首頁建議等於送出那則訊息，觸發的動作一樣要經過這些卡片。

限制：這是一套規則，不是保證。輸入你訊息裡給的文字不會問你，惡意網頁可能讀到它輸入的內容；惡意網頁也可能試著誘導模型做出規則沒涵蓋的事。在敏感網站上請留意它在做什麼。
