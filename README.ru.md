# Browser Agent

**ИИ-агент в вашем браузере, который работает прямо на сайте, который вы смотрите. Он читает страницу, кликает, вводит текст и переходит между страницами за вас — а когда одной страницы мало, исследует веб и отвечает с указанием источников.**

## Зачем

- **Работает на той странице, где вы уже находитесь.** Просите обычными словами: сделай сводку, собери цены в таблицу, заполни эту форму, найди настройку отмены подписки. Агент читает страницу и действует на ней — без копирования в отдельную вкладку чата.
- **Он видит страницу так, как её построил сайт.** Модель получает текст страницы и нумерованный список кнопок, ссылок и полей и кликает `ref: 12`, а не угадывает по скриншоту. Выделите абзац, чтобы спросить только о нём; PDF тоже работают.
- **Он умеет искать информацию и указывать источники.** Если ответа нет на этой странице, агент ищет в вашем собственном браузере, читает несколько страниц, сравнивает их и отвечает со ссылками `[n]`, ведущими к каждому источнику.
- **Рискованные действия ждут вас.** Клики и отправки форм, которые выглядят необратимыми, и страницы по адресам, которые агент составил сам, останавливаются, пока вы не нажмёте *Разрешить*. Эту проверку обеспечивает код расширения, а не вежливая просьба к модели.
- **Начните бесплатно или используйте свой ключ.** Сразу после установки он работает на Browser Agent Cloud с бесплатными ежемесячными кредитами и без регистрации. Предпочитаете своего провайдера? Переключитесь на собственный API-ключ в настройках, и запросы пойдут из вашего браузера прямо к этому провайдеру.

## Возможности

**Действия на странице**
- Инструменты: читать страницу, кликать, вводить текст (включая выпадающие списки `<select>`), прокручивать, открывать URL. Модель получает нумерованный список интерактивных элементов и кликает `ref: 12` вместо угадывания CSS-селекторов.
- Выделите текст на странице и спрашивайте только о нём; к сообщению прикрепляется выделение, а не вся вкладка.
- Прикрепить файлы к сообщению: перетащите, вставьте или выберите текстовые файлы, код или PDF, и их текст отправится вместе с тем, что вы набираете.
- PDF: текст извлекается с помощью pdf.js. Встроенный просмотрщик позволяет выделять текст в PDF так же, как на любой странице. Сканированные PDF (без текстового слоя) можно отправить в Claude как документ после того, как вы подтвердите стоимость.
- Главный экран: подсказки на основе страницы, на которой вы находитесь.

**Исследование по всему вебу**
- Ищет и читает страницы в фоновых вкладках вашего собственного браузера; страницы, на которые вы вошли в аккаунт, тоже работают, а текущая вкладка остаётся нетронутой.
- Каждая страница сжимается до того, что важно для вашего вопроса; источники пронумерованы, ссылки `[n]` кликабельны, а источники сохраняются вместе с разговором и включаются при его экспорте.
- Переходит по ссылкам со страниц, которые прочитал, и сразу идёт на исследовательские сайты вроде GitHub и npm; другие адреса сначала спрашивают.

**В разговоре**
- Потоковые ответы в Markdown с таблицами и блоками кода, а также сворачиваемые сводки рассуждений.
- Карточки с вопросами (`ask_user`): когда модели нужно решение, она спрашивает с кликабельными вариантами вместо угадывания.
- Карточки файлов: результаты в виде скачиваемых файлов `csv`, `json`, `md`, `txt`, `tsv`, `xml`, `yaml`, `ics` или `vcf`, с копированием и предпросмотром.

**Остаётся у вас**
- Проекты: дайте проекту собственные инструкции, файлы и память и выберите, какие навыки он использует. Каждый чат в проекте начинается с его инструкций; агент открывает файлы проекта только тогда, когда они ему нужны.
- Память: скажите «запомни …», и агент будет хранить краткие факты о вас между чатами. Просматривайте, редактируйте или отключайте в настройках.
- История: последние 30 разговоров каждого проекта, сгруппированные по дате. Откройте любой и продолжайте, либо экспортируйте в Markdown.
- 12 встроенных навыков и команд `/`; пишите свои или устанавливайте [Agent Skills](https://agentskills.io/specification) (`SKILL.md`, формат, который использует Claude Code) из GitHub, skills.sh или ClawHub.
- Интерфейс на 15 языках; светлая и тёмная темы следуют настройкам системы.

## Как работает исследование

Задайте вопрос, на который текущая страница ответить не может, — например, «какую библиотеку состояния для React выбрать в 2026 году?» — и агент проведёт исследование:

1. **Поиск.** Он открывает поиск в фоновой вкладке (Google; если Google просит подтвердить, что вы не робот, переключается на Bing), читает заголовки, ссылки и сниппеты и закрывает вкладку. Только если проверку требуют обе системы, вкладка поиска выходит на передний план, чтобы вы её прошли; после этого исследование продолжается само.
2. **Чтение.** Он открывает самые подходящие результаты в фоновых вкладках — до четырёх одновременно — и извлекает основной текст. Ваша текущая вкладка не затрагивается никогда.
3. **Сжатие.** Каждую страницу небольшая быстрая модель (Claude Haiku) сводит к тезисам, цитатам и датам, важным для вашего вопроса, чтобы двадцать страниц не завалили разговор и не раздули счёт.
4. **Ответ.** Сначала вы получаете вывод, затем сравнительную таблицу, рекомендацию с обоснованием и то, что источники не прояснили. Результаты поиска и прочитанные страницы пронумерованы: `[n]` в ответе — это ссылка, а использованные источники перечислены под ответом.

Каждый шаг виден на боковой панели, и в любой момент можно нажать «Стоп». Одна задача делает не более 40 шагов и читает не более 30 страниц.

## Быстрый старт

Требуется Chrome 122+.

1. Установите **[Browser Agent из Chrome Web Store](https://chromewebstore.google.com/detail/browser-agent/iebcachfohpddakkmnopkpfnjibdlhai)** — нажмите **Установить**. Обновляется автоматически.
2. Нажмите на значок на панели инструментов, чтобы открыть боковую панель (не видите его? закрепите через меню значка пазла), и согласитесь с кратким уведомлением о данных.
3. Спросите о странице, на которой вы находитесь, — или попросите что-нибудь исследовать. Ключ и аккаунт не нужны.

### Установка из zip-архива Release

Пока новая версия ждёт проверки в магазине, Release может быть новее версии в магазине. Node.js и сборка не нужны.

1. Скачайте `browser-agent-<version>.zip` из [последнего релиза](https://github.com/io-software-ai/browser-agent/releases/latest) и распакуйте его.
2. Откройте `chrome://extensions` и включите **Режим разработчика** (в правом верхнем углу).
3. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку, затем продолжите с шага 2 выше.

Чтобы обновиться, скачайте новый zip-архив, замените содержимое той же папки и нажмите значок перезагрузки на карточке расширения. Ваши настройки, чаты и память сохранятся. Загрузка из другой папки установит отдельную копию, которая начнётся с пустого состояния, — версия из магазина тоже.

### Сборка из исходного кода

Нужен Node.js 22+.

```bash
git clone https://github.com/io-software-ai/browser-agent.git
cd browser-agent
npm ci
npm run build
```

Затем загрузите папку `extension/` через **Загрузить распакованное расширение**, как в шаге 3. Если не задать `BA_BACKEND` при сборке, версия из исходников обращается к серверу Browser Agent Cloud по адресу `http://localhost:4410`, поэтому используйте собственный API-ключ (ниже) или укажите бэкенд, который вы запускаете сами.

## Два способа использования

| | Browser Agent Cloud (по умолчанию) | Свой API-ключ |
|---|---|---|
| Настройка | Не нужна — работает сразу после установки | **Настройки → Свой API-ключ (дополнительно)**, затем вставьте ключ или локальный адрес |
| Аккаунт | Не нужен; при установке создаётся анонимный ID устройства | Не нужен |
| Модели | Claude Sonnet, Opus и Haiku (5.5) | То, что предлагает ваш провайдер |
| Стоимость | Бесплатные ежемесячные кредиты; платные тарифы для большего объёма (оплата через Paddle) | Оплачивается вашему провайдеру; расширение бесплатно |
| Куда идут запросы | Через сервер Browser Agent Cloud к провайдеру модели | Прямо из вашего браузера к вашему провайдеру |

**Кредиты.** В режиме Cloud каждая задача (одно отправленное вами сообщение — до остановки агента) расходует фиксированное число кредитов, которое зависит от модели, глубины рассуждения и того, какой объём каждой страницы читается. Боковая панель показывает оценку до отправки и остаток кредитов после каждой задачи. Когда кредиты заканчиваются, задачи приостанавливаются до следующего месяца или до перехода на платный тариф.

**Свой ключ.** Работают эти провайдеры; выбирайте модель с поддержкой вызова инструментов, иначе агент не сможет действовать на странице.

| Провайдер | Что нужно | Примечания |
|---|---|---|
| Anthropic | [API-ключ](https://console.anthropic.com/settings/keys) | Sonnet 5.5, Opus 5.5, Haiku 5.5; глубина рассуждения; сводки рассуждений; сканированные PDF; сводка каждой страницы при исследовании |
| OpenAI | [API-ключ](https://platform.openai.com/api-keys) | Список моделей запрашивается у провайдера |
| Google Gemini | [API-ключ](https://aistudio.google.com/apikey) | Использует совместимый с OpenAI endpoint Gemini |
| OpenRouter | [API-ключ](https://openrouter.ai/keys) | Любая модель на OpenRouter с поддержкой инструментов |
| Свой (совместимый с OpenAI) | Базовый URL, ключ необязателен | Ollama, LM Studio, vLLM, llama.cpp — всё, что поддерживает `/chat/completions` |

У провайдеров, кроме Anthropic, исследование читает каждую страницу как сырой текст вместо сводки от Haiku, и это расходует больше токенов.

Локальные серверы по умолчанию блокируют расширения браузера:

- **Ollama:** установите `OLLAMA_ORIGINS=chrome-extension://*` и перезапустите Ollama (macOS: `launchctl setenv OLLAMA_ORIGINS "chrome-extension://*"`). Базовый URL `http://localhost:11434/v1`.
- **LM Studio:** запустите сервер с включённым CORS, `lms server start --cors`. Базовый URL `http://localhost:1234/v1`.

## Навыки

Введите `/` в поле сообщения, чтобы выбрать навык, или дайте модели загрузить подходящий самой.

| Команда | Что делает |
|---|---|
| `/summarize` | Краткий вывод в одну строку, ключевые пункты и задачи по текущей странице |
| `/translate` | Переводит страницу на ваш язык, сохраняя заголовки и абзацы |
| `/extract` | Извлекает данные страницы в таблицу Markdown; файл CSV или JSON, если данных много |
| `/compare` | Строит сравнительную таблицу цен, тарифов или характеристик и выделяет различия |
| `/explain` | Объясняет страницу, термин или фрагмент кода простыми словами |
| `/thread` | Подводит итог обсуждения: основные аргументы, позиции сторон, консенсус, комментарии, которые стоит прочитать |
| `/reply` | Составляет черновик ответа на письмо или сообщение на странице; может заполнить поле ответа, но никогда не отправляет |
| `/fill-form` | Заполняет форму вашими данными; спрашивает о недостающем, останавливается перед отправкой |
| `/review-pr` | Проверяет pull request на GitHub и перечисляет проблемы по степени серьёзности, с файлом и строкой |
| `/checklist` | Превращает туториал в чек-лист шагов |
| `/decide` | Раскладывает варианты, по очереди спрашивает о ваших потребностях, затем рекомендует один |
| `/grill-me` | Проверяет ваш план (или предложение на странице) вопросами с выбором ответа, по одному за раз |

`/clear` начинает новый разговор. Для исследования команда не нужна — просто попросите.

### Напишите свой

Навык — это файл Markdown с фронтматтером `name` и `description`, за которым следуют инструкции:

```markdown
---
name: meeting-notes
description: Turn a meeting page into decisions, action items and owners
---

1. Read the whole page with read_page.
2. List decisions, then a table of action items with owner and due date.
```

Управляйте навыками в **Настройки → Навыки**: создавайте, редактируйте, экспортируйте, импортируйте файл `.md`, `.zip`/`.skill` или целую папку навыка, либо устанавливайте по ссылке — `owner/repo/skill`, ссылка на папку GitHub, страница skills.sh или её команда `npx skills add …`, страница ClawHub или любая https-ссылка на `SKILL.md` либо zip. Навыки следуют стандарту [Agent Skills](https://agentskills.io/specification) — тому же формату `SKILL.md`, который используют Claude Code и другие агенты. Файлы, поставляемые с навыком (например, `references/forms.md`), сохраняются, и модель читает их, только когда на них ссылаются инструкции; поставляемые скрипты хранятся как текст и никогда не запускаются. Необязательная строка `model:` (например, `model: haiku`) запускает этот навык на более дешёвой модели Claude; `disable-model-invocation: true` и `user-invocable: false` работают как в Claude Code, а `$ARGUMENTS` заменяется тем, что вы вводите после `/name`.

В системный промпт попадают только названия и описания; модель вызывает `use_skill`, чтобы загрузить полные инструкции, когда они нужны, а ввод `/имя` прикрепляет их напрямую. Навыки — это промпты: прочитайте навык перед импортом.

## Безопасность и конфиденциальность

**Поток данных.** Запрос к модели содержит ваши сообщения, содержимое страницы, которое прочитал агент (или только ваше выделение, или PDF), сводки страниц, прочитанных при исследовании, сохранённую память и названия ваших навыков. В проекте он также содержит инструкции и память проекта; файлы, которые вы прикрепляете к сообщению, и файлы проекта, которые открывает агент, тоже отправляются.

- *Режим Cloud* отправляет этот запрос на сервер Browser Agent Cloud, который пересылает его провайдеру модели и передаёт ответ потоком обратно. Сервер ведёт записи об использовании — какая модель, сколько токенов, страниц, поисковых запросов и кредитов ушло на задачу, — чтобы считать кредиты. Он не хранит ваши сообщения, содержимое страниц и ответы модели; если провайдер модели возвращает ошибку, текст этой ошибки может сохраняться вместе с записью об использовании для отладки.
- *Свой ключ* отправляет запросы прямо из вашего браузера вашему провайдеру. Ничего о ваших задачах не попадает на серверы Browser Agent; единственный контакт — анонимная регистрация, выполненная при установке расширения.

Ваши разговоры, память, навыки, настройки и любой API-ключ хранятся только в `chrome.storage.local`. Никакой аналитики, никакой рекламы. Ничего не отправляется модели, пока вы не согласитесь с уведомлением о данных при первом запуске. Подробности: [политика конфиденциальности](store/privacy-policy.md).

**Исследование использует ваш браузер.** Фоновые вкладки загружают страницы с вашими cookie и авторизованными сессиями — точно так же, как если бы вы открыли их сами; PDF скачиваются напрямую расширением, тоже с вашими cookie. Поиск — это обычный поиск в Google (или Bing) из вашего браузера, поэтому, если вы вошли в аккаунт, запросы могут сохраняться в истории поиска этого аккаунта. Поисковые запросы формулирует модель на основе вашего вопроса.

**Что требует вашего *Разрешить*.** Эти действия показывают карточку на боковой панели и не выполняются, пока вы не нажмёте *Разрешить*. Карточка находится на собственной странице расширения, которую сайт не может кликнуть за вас:

- клики и отправки форм, которые выглядят необратимыми: видимый текст кнопки, `aria-label`, title или value читаются как «оплатить», «купить», «заказать», «удалить», «отправить», «опубликовать», «авторизовать», «сохранить», «поделиться», «установить» и похожие (на всех 15 языках интерфейса); форма с несколькими полями или полем пароля; кнопка только с иконкой внутри формы; нажатие Enter в поле не внутри формы (чат-окна). Если видимый текст кнопки и её `aria-label` расходятся, карточка предупреждает вас;
- переход на другой сайт в вашей вкладке, через навигацию или клик по ссылке, если это не тот сайт, с которого началась задача, не сайт, названный вами в сообщении, и не сайт, уже разрешённый в этой задаче. Если разговор уже содержит веб-контент или файлы, агент спрашивает также перед переходом по любому адресу, который он составил сам, даже на этих сайтах; без вопроса проходят только точные адреса из вашего сообщения, результатов поиска или прочитанных страниц;
- чтение в фоне страницы, адрес которой агент составил сам. Без вопроса он читает только точные адреса из результатов поиска, ссылки на страницах, которые уже прочитал, адреса из вашего сообщения и исследовательские сайты (GitHub, npm). Страницы на `localhost` или в вашей локальной сети не читаются, если адрес не набрали вы сами; для страниц, открываемых в фоновой вкладке, это касается и публичных доменов, которые указывают на локальный адрес (для PDF проверяется только сам адрес);
- ввод на странице текста, которого нет в вашем сообщении, если разговор уже содержит веб-контент или файлы (страница может прочитать то, что вводится в её поля, даже если ничего не отправлено);
- сохранение или удаление записи в памяти, если разговор уже содержит веб-контент или файлы (прочитанную страницу, PDF, выделение, файл проекта или вложение).

**Файлы считаются веб-контентом.** Файлы, которые вы загружаете в проект или прикрепляете к сообщению, часто скачаны из интернета, поэтому их названия и содержимое считаются недоверенными: как только агент прочитал один из них, описанные выше карточки действуют до конца задачи, а инструкции внутри файла не выполняются как ваши. Названия файлов не попадают в инструкции для модели.

Карточки, связанные с адресом, показывают его вместе со строкой запроса, потому что адрес может вынести данные наружу; очень длинные адреса сокращаются, при этом сохраняются домен и начало строки запроса.

Клик по подсказке сразу отправляет её. Подсказки, сгенерированные на основе страницы, пишутся после чтения её содержимого, поэтому страница может на них повлиять: упомянутые в них сайты не считаются названными вами, а всё, что они запускают, всё равно проходит через те же карточки. Ссылки в ответах показывают свой настоящий домен рядом с текстом; список источников показывает домен каждого источника.

**Вывод и файлы.** Ответы модели рендерятся с помощью DOMPurify. Изображения, медиа, SVG, iframe, формы и inline-стили удаляются, так что страница не может заставить модель слить вашу переписку через URL изображения. Генерируемые файлы — только текстовые форматы (`csv`, `json`, `md`, …), а ячейки CSV/TSV, начинающиеся как формула электронной таблицы, нейтрализуются.

### Известные ограничения

- **Проблема prompt injection не решена.** Агент читает много непроверенных страниц с вашей авторизованной сессией. Вредоносная страница может попытаться направить его на отправку вашей переписки, памяти или данных с других сайтов куда-либо, либо заставить его действовать за вас. Карточки покрывают перечисленные выше действия высокого риска; это не полная защита. Небольшие объёмы данных всё равно могут утечь через то, по каким ссылкам агент решает перейти или что он ищет.
- Не проводите исследования и не запускайте задачи на непроверенных страницах, пока открыты вкладки с банком, почтой или админкой компании, и следите за агентом, пока выполняется задача.
- Обнаружение рискованных кликов — это эвристика по ключевым словам и форме формы. Некоторые кнопки будут пропущены.
- Ввод ваших собственных слов (из вашего сообщения) в поле не запрашивает подтверждение. Вредоносная страница может прочитать, что вводит агент (например, через слушатель `input`), и отправить это на свой сервер.
- Импортированные и установленные навыки — это инструкции третьих лиц. Пока такой навык есть в вашем списке навыков (или вы вызываете его через `/name`), любая задача считается недоверенной: сохранение воспоминания, открытие ссылки, собранной агентом, или ввод текста, который вы не давали, сначала запрашивают подтверждение. Такие навыки отмечены в списке меткой *Сторонний*. Навыки, которые вы написали сами, считаются доверенными. У навыков, добавленных до этой версии, нет записи об источнике, поэтому они тоже считаются сторонними; если вы написали такой навык сами, откройте его и выберите **Я написал это сам**. Устанавливайте навыки только из источников, которым вы доверяете.
- Память, проекты (вместе с их файлами) и разговоры хранятся в браузере в незашифрованном виде. Память и инструкции проектов отправляются модели с каждым запросом (через Browser Agent Cloud или вашему собственному провайдеру).

## Разработка

```bash
npm run watch      # rebuild on save; then click reload on the extension card
npm run typecheck  # tsc --noEmit
npm run check      # unit self-checks: skills, memory, history, files, providers, security, i18n
npm run test:e2e   # builds into dist/e2e-ext and runs it in Playwright against mocked model, backend, search and websites
```

Боковая панель — это React + TypeScript, собранный esbuild в `extension/`. `src/agent.ts` выполняет цикл агента на боковой панели: в режиме Cloud он вызывает API Browser Agent Cloud (совместимый с Anthropic, адрес задаётся `BA_BACKEND` при сборке) через официальный SDK; со своим ключом — вызывает Anthropic напрямую или любой совместимый с OpenAI API через `src/providers.ts`. Инструменты в `src/tools.ts` выполняются на активной или в фоновых вкладках через `chrome.scripting`; `src/elements.ts` строит нумерованный список элементов и проверку необратимых действий. Набор e2e-тестов не требует API-ключа, ничего не стоит и не отправляет запросов в настоящий интернет.

Назначение каждого файла см. в таблице в разделе [Development](README.md#development) английской версии. Чтобы добавить инструмент: добавьте его схему в `tools` в `src/shared.ts` и `case` в `runTool` в `src/tools.ts`.

### Перевод

Скопируйте `src/i18n/locales/en.ts` в, например, `nl.ts`, объявите его как `const nl: Dict = { … }`, переведите значения (сохраняя каждый `{placeholder}`) и добавьте его в `LANGS` и загрузчики в `src/i18n/index.ts`. `npm run typecheck` завершится ошибкой при отсутствующем или лишнем ключе; `npm run check` — при несовпадающем placeholder. Промпты и описания инструментов, отправляемые модели, намеренно остаются на одном языке. Для названия и описания в Chrome Web Store добавьте `extension/_locales/<code>/messages.json` (Chrome использует подчёркивания, например, `pt_BR`).
