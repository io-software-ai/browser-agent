**AI エージェントをブラウザに。今見ているサイトの上で直接作業します。ページを読み、クリックし、入力し、ページ間を移動する——そして 1 ページで足りないときは、Web 全体を調べて出典つきで答えます。**

## なぜ使うのか

- **今開いているページで、そのまま作業できます。** 「このページを要約して」「価格を表にして」「このフォームを埋めて」「解約の設定を探して」と普通の言葉で頼むだけ。ページを読み取って、そのまま操作します。チャット用の別タブにコピペする必要はありません。
- **サイトが作ったとおりの構造でページを捉えます。** モデルに渡されるのはページのテキストと、番号付きのボタン・リンク・入力欄の一覧。スクリーンショットから位置を推測するのではなく、`ref: 12` を指定してクリックします。段落を選択すればその部分だけについて質問でき、PDF にも対応しています。
- **出典つきで調べものもできます。** 答えがこのページにないときは、あなた自身のブラウザで検索し、いくつかのページを読んで比較し、各出典へリンクする `[n]` 付きで答えます。
- **危険な操作は、あなたの許可を待ちます。** 取り消せなさそうなクリックやフォーム送信、エージェントが自分で組み立てたアドレスのページは、**許可**を押すまで止まります。このチェックは拡張機能のコードが強制するもので、モデルにお願いしているだけではありません。
- **無料で始められ、自分のキーも使えます。** インストールしてすぐ、登録なしで毎月の無料クレジット付きの Browser Agent Cloud が使えます。自分のプロバイダーを使いたい場合は、設定で自分の API キーに切り替えると、リクエストはブラウザからそのプロバイダーへ直接送られます。

## 機能

**ページを操作する**
- ツール：ページの読み取り、クリック、入力（`<select>` のドロップダウンも含む）、スクロール、URL を開く。モデルには番号付きの操作可能な要素の一覧が渡され、CSS セレクターを推測する代わりに `ref: 12` をクリックします。
- ページ上のテキストを選択して、その部分だけについて質問できます。メッセージに添付されるのはタブ全体ではなく、選択した部分です。
- PDF：pdf.js でテキストを抽出します。内蔵ビューアーを使えば、一般的なページと同じように PDF のテキストを選択できます。スキャンされた PDF（テキストレイヤーなし）は、費用を確認したうえで、ドキュメントとして Claude に送れます。
- ホーム画面：開いているページに合わせた提案を表示します。

**Web 全体を調べる**
- ご自身のブラウザのバックグラウンドタブで検索・閲覧します。ログイン済みのページも読め、今開いているタブには触れません。
- 各ページは質問に関係する要点に絞り込まれます。出典には番号が付き、`[n]` の引用はクリックでき、出典は会話と一緒に保存されて、エクスポート時にも含まれます。
- 読んだページ内のリンクをたどり、GitHub や npm のような調査向けサイトには直接アクセスします。それ以外のアドレスは先に確認します。

**会話の中で**
- ストリーミング表示の Markdown 返信。表やコードブロックに対応し、折りたたみ式の思考の要約もあります。
- 質問カード（`ask_user`）：モデルが判断を必要とするときは、推測せずクリックできる選択肢で尋ねます。
- ファイルカード：結果を `csv`、`json`、`md`、`txt`、`tsv`、`xml`、`yaml`、`ics`、`vcf` のファイルとしてダウンロードでき、コピーやプレビューもできます。

**手元に残せる**
- メモリ：「覚えて……」と言えば、あなたに関する短い事実を会話をまたいで覚えておきます。設定で確認・編集・オフにできます。
- 履歴：直近 30 件の会話を日付ごとにまとめて表示。開き直して続けたり、Markdown としてエクスポートしたりできます。
- 12 個の内蔵スキルと `/` コマンド。自作するか、GitHub・skills.sh・ClawHub から [Agent Skills](https://agentskills.io/specification)（Claude Code が使う `SKILL.md` 形式）をインストールできます。
- 15 言語に対応したインターフェース。ライト／ダークテーマはシステムの設定に従います。

## リサーチの流れ

今のページでは答えられない質問——たとえば「2026 年に使う React の状態管理ライブラリはどれがいい？」——をすると、エージェントは次のように調べます。

1. **検索。** バックグラウンドタブで検索を開きます（Google。Google が人間かどうかの確認を求めてきた場合は Bing に切り替えます）。タイトル、リンク、スニペットを読み取り、タブを閉じます。両方で確認を求められた場合に限り、検索タブが前面に出てくるので、あなたが確認を済ませると、リサーチは自動で続きます。
2. **閲覧。** 最も関連性の高い結果をバックグラウンドタブで開き（同時に最大 4 つまで）、本文を抽出します。今開いているタブには一切触れません。
3. **要約。** 各ページは、小さくて高速なモデル（Claude Haiku）が、質問に関係するポイント、引用、日付だけに絞り込みます。20 ページ分の全文で会話があふれたり、料金がかさんだりすることはありません。
4. **回答。** まず結論、続いて比較表、理由つきのおすすめ、出典では決着がつかなかった点を示します。検索結果と読んだページには番号が付き、回答中の `[n]` はリンクになっていて、引用された出典は返信の下に一覧表示されます。

すべてのステップはサイドパネルで確認でき、いつでも停止を押せます。1 つのタスクで実行できるのは最大 40 ステップ、読めるのは最大 30 ページです。

## クイックスタート

Chrome 122 以降が必要です。

1. **[Chrome ウェブストアから Browser Agent をインストール](https://chromewebstore.google.com/detail/browser-agent/iebcachfohpddakkmnopkpfnjibdlhai)**し、**Chrome に追加**をクリックします。以降は自動的に更新されます。
2. ツールバーのアイコンをクリックしてサイドパネルを開き（見当たらない場合はパズルピースのアイコンのメニューからピン留めしてください）、簡単なデータに関する通知に同意します。
3. 今開いているページについて質問するか、何かを調べてもらいましょう。キーもアカウントも不要です。

### リリースの zip からインストールする

新しいバージョンが審査待ちの間は、リリースのほうがストアより新しいことがあります。Node.js もビルド作業も不要です。

1. [最新リリース](https://github.com/io-software-ai/browser-agent/releases/latest)から `browser-agent-<バージョン>.zip` をダウンロードして解凍します。
2. `chrome://extensions` を開き、右上の**デベロッパー モード**をオンにします。
3. **パッケージ化されていない拡張機能を読み込む**をクリックし、解凍したフォルダを選びます。続きは上の手順 2 から進めてください。

更新するときは、新しい zip をダウンロードして同じフォルダの中身を置き換え、拡張機能カードの再読み込みアイコンをクリックしてください。設定、会話、メモリはそのまま引き継がれます。別のフォルダから読み込むと、中身が空の別インスタンスとしてインストールされます——ストア版も同じです。

### ソースからビルドする

Node.js 22 以上が必要です。

```bash
git clone https://github.com/io-software-ai/browser-agent.git
cd browser-agent
npm ci
npm run build
```

あとは手順 3 と同様に、**パッケージ化されていない拡張機能を読み込む**で `extension/` フォルダを選択してください。ソースからビルドしたものは、ビルド時に `BA_BACKEND` を指定しない限り `http://localhost:4410` の Browser Agent Cloud サーバーに接続します。そのため、自分の API キー（下記）を使うか、自分で用意したバックエンドを指定してください。

## 2 つの使い方

| | Browser Agent Cloud（デフォルト） | 自分の API キー |
|---|---|---|
| セットアップ | 不要。インストールしてすぐ使える | **設定 → 自分の API キーを使う（上級者向け）**で、キーまたはローカルのエンドポイントを貼り付ける |
| アカウント | なし。インストール時に匿名のデバイス ID が作られる | なし |
| モデル | Claude Sonnet、Opus、Haiku（5.5） | プロバイダーが提供するもの |
| 費用 | 毎月の無料クレジット。さらに必要なら有料プラン（決済は Paddle） | プロバイダーから請求される。拡張機能自体は無料 |
| リクエストの送信先 | Browser Agent Cloud サーバー経由でモデルプロバイダーへ | ブラウザからプロバイダーへ直接 |

**クレジット。** Cloud モードでは、1 つのタスク（あなたが送った 1 件のメッセージから、エージェントが止まるまで）につき、モデル、思考の深さ、各ページをどれだけ読むかで決まる固定数のクレジットを消費します。送信前にサイドパネルに見積もりが表示され、タスクが終わるたびに残りのクレジットが表示されます。使い切ると、翌月になるかアップグレードするまでタスクは一時停止します。

**自分のキー。** 次のプロバイダーが使えます。ツール呼び出しに対応したモデルを選んでください。そうでないと、エージェントはページを操作できません。

| プロバイダー | 必要なもの | 備考 |
|---|---|---|
| Anthropic | [API キー](https://console.anthropic.com/settings/keys) | Sonnet 5.5、Opus 5.5、Haiku 5.5。思考の深さ、思考の要約、スキャンされた PDF、ページごとのリサーチ要約に対応 |
| OpenAI | [API キー](https://platform.openai.com/api-keys) | モデル一覧はプロバイダーから取得 |
| Google Gemini | [API キー](https://aistudio.google.com/apikey) | Gemini の OpenAI 互換エンドポイントを使用 |
| OpenRouter | [API キー](https://openrouter.ai/keys) | OpenRouter 上のツール対応モデルならどれでも |
| カスタム（OpenAI 互換） | Base URL（キーは省略可） | Ollama、LM Studio、vLLM、llama.cpp など、`/chat/completions` を備えたもの全般 |

Anthropic 以外のプロバイダーでは、リサーチで読んだ各ページが Haiku による要約ではなく生のテキストとして渡されるため、トークンの消費が増えます。

ローカルサーバーは、デフォルトではブラウザ拡張機能からのアクセスをブロックします。

- **Ollama：** `OLLAMA_ORIGINS=chrome-extension://*` を設定して Ollama を再起動します（macOS：`launchctl setenv OLLAMA_ORIGINS "chrome-extension://*"`）。Base URL は `http://localhost:11434/v1`。
- **LM Studio：** CORS を有効にしてサーバーを起動します：`lms server start --cors`。Base URL は `http://localhost:1234/v1`。

## スキル

入力欄で `/` を入力して選ぶか、状況に合わせてモデル自身に読み込ませることもできます。

| コマンド | 内容 |
|---|---|
| `/summarize` | 今のページの要点を 1 行で、さらに重要ポイントとアクションアイテムを整理 |
| `/translate` | ページをあなたの言語に翻訳し、見出しと段落の構成を保つ |
| `/extract` | ページ上のデータを Markdown の表にまとめる。量が多いときは CSV または JSON ファイルも用意 |
| `/compare` | 価格・プラン・スペックの比較表を作り、違いを強調 |
| `/explain` | ページ、用語、コードの一部をやさしい言葉で説明 |
| `/thread` | コメントスレッドを要約：主な論点、それぞれの立場、合意点、読む価値のあるコメント |
| `/reply` | ページ上のメールやメッセージへの返信を下書き。返信欄に入力はするが、送信は決してしない |
| `/fill-form` | あなたの情報でフォームを入力。足りない項目は質問し、送信の手前で止まる |
| `/review-pr` | GitHub のプルリクエストをレビューし、問題を重大度順に、ファイルと行つきで列挙 |
| `/checklist` | チュートリアルを手順のチェックリストに変換 |
| `/decide` | 選択肢を整理し、あなたのニーズを 1 問ずつ尋ねてから、1 つをおすすめ |
| `/grill-me` | 1 回に 1 問の選択式で、あなたの計画（またはページ上の提案）を徹底的に問いただす |

`/clear` で新しい会話を始められます。リサーチにコマンドは不要で、そのまま頼むだけです。

### 自分で作る

スキルは、`name` と `description` を持つ frontmatter に続けて指示を書いた Markdown ファイルです。

```markdown
---
name: meeting-notes
description: Turn a meeting page into decisions, action items and owners
---

1. Read the whole page with read_page.
2. List decisions, then a table of action items with owner and due date.
```

スキルは**設定 → スキル**で管理できます：作成、編集、エクスポート、`.md`・`.zip`/`.skill` ファイルやスキルフォルダ丸ごとのインポート、またはリンクからのインストール（`owner/repo/skill`、GitHub のフォルダリンク、skills.sh のページまたはその `npx skills add …` コマンド、ClawHub のページ、`SKILL.md` や zip への任意の https リンク）。スキルは [Agent Skills](https://agentskills.io/specification) 標準に従っており、Claude Code や他のエージェントと同じ `SKILL.md` 形式です。スキルに同梱されたファイル（たとえば `references/forms.md`）は保存され、指示から参照されたときだけモデルが読み取ります。同梱のスクリプトはテキストとして保持され、実行されることはありません。任意の `model:` 行（たとえば `model: haiku`）を付けると、そのスキルをより安価な Claude モデルで実行します。`disable-model-invocation: true` と `user-invocable: false` は Claude Code と同じように動作し、`$ARGUMENTS` は `/name` の後に入力した内容に置き換えられます。

システムプロンプトに含まれるのは名前と説明だけです。モデルは必要になったときに `use_skill` を呼び出して完全な指示を読み込み、`/名前` と入力すると直接アタッチされます。スキルはプロンプトそのものなので、インポートする前に内容を読んでおきましょう。

## セキュリティとプライバシー

**データの流れ。** モデルへの 1 回のリクエストには、あなたのメッセージ、エージェントが読んだページの内容（または選択範囲だけ、あるいは PDF）、リサーチしたページの要約、保存されたメモリ、スキル名が含まれます。

- *Cloud モード*では、そのリクエストを Browser Agent Cloud サーバーに送り、サーバーがモデルプロバイダーへ転送して、返信をストリームで返します。サーバーはクレジットを数えるために利用記録を保持します。タスクで使ったモデル、トークン数、ページ数、検索回数、クレジット数などです。あなたのメッセージ、ページの内容、モデルの返信は保存しません。ただし、モデルプロバイダーがエラーを返した場合は、そのエラーメッセージが調査用に利用記録と一緒に残ることがあります。
- *自分のキー*では、リクエストはブラウザからプロバイダーへ直接送られます。タスクに関する情報が Browser Agent のサーバーに届くことはなく、唯一の接触は、拡張機能のインストール時に行われる匿名の登録だけです。

会話、メモリ、スキル、設定、API キーは `chrome.storage.local` にのみ保存されます。アナリティクスも広告もありません。初回起動時のデータに関する通知に同意するまで、モデルには何も送信されません。詳細は[プライバシーポリシー](store/privacy-policy.md)をご覧ください。

**リサーチはあなたのブラウザを使います。** バックグラウンドタブは、あなたが自分で開いたときと同じように、あなたの cookie とログイン済みのセッションでページを読み込みます。PDF は拡張機能が直接ダウンロードし、これも cookie つきです。検索はブラウザからの通常の Google（または Bing）検索なので、ログインしていれば、そのアカウントの検索履歴に残ることがあります。検索キーワードは、あなたの質問をもとにモデルが作成します。

**「許可」が必要な操作。** 以下の操作はサイドパネルにカードを表示し、**許可**を押すまで実行されません。カードは拡張機能自身のページ内にあるため、Web サイト側からクリックすることはできません。

- 取り消せなさそうなクリックやフォーム送信：ボタンの表示テキスト、`aria-label`、title、value が、支払い、購入、注文、削除、送信、発信、公開、承認、保存、共有、インストールなどを意味するように読めるもの（15 のインターフェース言語すべてで判定）。複数の入力欄やパスワード欄があるフォーム。フォーム内のアイコンだけのボタン。フォームに属さない入力欄での Enter キー（チャット欄）。ボタンの表示テキストと `aria-label` が食い違っている場合は、カードで警告します。
- タブを別のサイトへ移動させること（ナビゲーションでもリンクのクリックでも）。ただし、タスク開始時のサイト、あなたがメッセージで指定したサイト、このタスク内ですでに許可したサイトのいずれかは除きます。
- エージェントが自分で組み立てたアドレスのページをバックグラウンドで読むこと。確認なしで読めるのは、検索結果にあるアドレス、すでに読んだページ内のリンク、あなたのメッセージに含まれるアドレスと完全に一致するもの、そして調査向けサイト（GitHub、npm）だけです。`localhost` やローカルネットワーク上のページは、あなたが入力したアドレスでない限り読みません。バックグラウンドタブで開くページでは、ローカルのアドレスに解決される公開ドメインもこの対象です（PDF はアドレス自体のみ検査）。
- 会話に Web のコンテンツ（読んだページ、PDF、選択範囲）が含まれたあとの、メモリへの保存。

アドレスを伴うカードには、クエリ文字列も含めてアドレスを表示します。アドレスはデータを外へ持ち出せるためです。非常に長いアドレスは短縮されますが、ドメインとクエリ文字列の先頭は残ります。

候補をクリックすると、すぐに送信されます。ページから生成された候補は、ページの内容を読んだあとに書かれるため、ページがその内容に影響を与える可能性があります。候補に出てくるサイトは、あなたが指定したサイトとは見なされず、そこから起こる操作も同じカードを通ります。返信内のリンクには、テキストの横に実際のドメインが表示され、出典一覧には各出典のドメインが表示されます。

**出力とファイル。** モデルの返信は DOMPurify で描画されます。画像、メディア、SVG、iframe、フォーム、インラインスタイルは取り除かれるため、ページがモデルを誘導して、画像の URL 経由で会話を漏らさせることはできません。生成されるファイルはプレーンテキスト形式（`csv`、`json`、`md` など）に限られ、CSV/TSV のセルのうちスプレッドシートの数式のように始まるものは無害化されます。

### 既知の制限

- **プロンプトインジェクションは解決されていません。** エージェントは、ログイン済みのセッションで、信頼できない多くのページを読みます。悪意のあるページが、会話やメモリ、他のサイトのデータをどこかへ送らせたり、あなたに代わって何かをさせたりしようとする可能性があります。上記のカードは危険度の高い操作をカバーしますが、完全な防御ではありません。エージェントがどのリンクをたどるか、何を検索するかによって、少量のデータが漏れる可能性は残ります。
- ネットバンキング、メール、社内の管理画面を開いたタブがあるあいだは、信頼できないページでリサーチやタスクを実行しないでください。タスクの実行中は目を離さないようにしましょう。
- 危険なクリックの検出は、キーワードとフォームの形に基づくヒューリスティックです。見逃すボタンもあります。
- 同じサイト内の入力欄への入力では確認しません。悪意のあるページは、エージェントが入力した内容を（たとえば `input` リスナーで）読み取り、自分のサーバーへ送ることができます。
- インポートしたスキルやインストールしたスキルは第三者の指示です。スキル一覧にある間（または `/name` で呼び出した間）は、すべてのタスクが信頼できないものとして扱われます。メモリの保存、エージェントが組み立てたリンクを開くこと、あなたが与えていないテキストの入力は、事前に確認を求めます。これらのスキルは一覧に「サードパーティ」ラベルが付きます。自分で書いたスキルは信頼されたものとして扱われます。このバージョンより前に追加したスキルは提供元の記録がないため、同じくサードパーティとして扱われます。自分で書いたものなら、開いて**自分で書きました**を選んでください。信頼できる提供元のスキルだけをインストールしてください。
- メモリと会話は暗号化されずにブラウザへ保存され、リクエストのたびにモデルへ送られます（Browser Agent Cloud 経由、または自分のプロバイダーへ）。

## 対応言語

English、繁體中文、简体中文、日本語、한국어、Español、Français、Deutsch、Português (Brasil)、Italiano、Русский、Tiếng Việt、Bahasa Indonesia、ไทย、Türkçe。デフォルトはブラウザの言語に従い、**設定 → 言語**で変更できます。別の言語で書かない限り、モデルはインターフェースの言語で回答します。

## 開発

```bash
npm run watch      # 保存のたびに再ビルド；その後、拡張機能カードの再読み込みをクリック
npm run typecheck  # tsc --noEmit
npm run check      # 単体のセルフチェック：スキル、メモリ、履歴、ファイル、プロバイダー、セキュリティ、i18n
npm run test:e2e   # dist/e2e-ext にビルドし、モックのモデル・バックエンド・検索・Web サイトを相手に Playwright で実行
```

サイドパネルは React + TypeScript で、esbuild により `extension/` にバンドルされます。`src/agent.ts` がサイドパネル内でエージェントループを実行します。Cloud モードでは公式 SDK で Browser Agent Cloud の API（Anthropic 互換。アドレスはビルド時に `BA_BACKEND` で指定）を呼び出し、自分のキーでは Anthropic を直接、または `src/providers.ts` 経由で任意の OpenAI 互換 API を呼び出します。`src/tools.ts` のツールは `chrome.scripting` を使い、アクティブなタブまたはバックグラウンドタブで実行されます。`src/elements.ts` は番号付きの要素一覧と、取り消せない操作の判定を作ります。e2e テストに API キーは不要で、費用もかからず、実際のインターネットへのリクエストも発生しません。

各ファイルの役割は、英語版 [Development](README.md#development) の表を参照してください。ツールを追加するには、`src/shared.ts` の `tools` にスキーマを追加し、`src/tools.ts` の `runTool` に `case` を追加します。

### 翻訳

`src/i18n/locales/en.ts` を例えば `nl.ts` としてコピーし、`const nl: Dict = { … }` として宣言し、値を翻訳します（`{placeholder}` はすべて残してください）。そのうえで `src/i18n/index.ts` の `LANGS` とローダーに追加します。キーが不足または余分だと `npm run typecheck` が失敗し、プレースホルダーが一致しないと `npm run check` が失敗します。モデルに送られるプロンプトとツールの説明は、意図的に単一言語のまま保たれています。Chrome ウェブストアの名称と説明は `extension/_locales/<code>/messages.json` に追加してください（Chrome はアンダースコアを使うので、例えば `pt_BR`）。
